环境变量速查（高频）

变量作用
CODEGRAPH_MCP_TOOLS重新启用非默认工具，如 explore,node
CODEGRAPH_NO_DAEMON=1禁用 daemon，单进程 direct 模式
CODEGRAPH_KERNEL=0关闭 Rust 内核，全部走 WASM
CODEGRAPH_NO_WATCHDOG=1关闭 liveness watchdog
CODEGRAPH_PARSE_WORKERS覆盖解析池大小（0/1 回滚单线程）
CODEGRAPH_WAL_VALVE_MB / CODEGRAPH_WAL_HEAL_MBWAL 阈值调优
CODEGRAPH_DIR数据目录改名（Windows/WSL 共树场景）
DO_NOT_TRACK=1 / CODEGRAPH_TELEMETRY=0关闭遥测
