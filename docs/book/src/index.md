# CodeGraph 源码导读

**从 tree-sitter 到 MCP:CodeGraph 的架构、源码与设计取舍。**

CodeGraph 是一个本地优先的代码情报系统:用 tree-sitter 把任意代码库解析成一张可查询的图(符号、调用、路由、影响半径),通过 CLI / 库 / MCP 服务器三种形态,为 AI 编码 agent 提供"少数几次结构化查询就足以停止阅读"的答案。

本书逐层解剖这条管线——从语法树到 SQLite,从引用解析到进程拓扑——每一章都锚定在真实源码上,并解释那些"非常规写法"背后的事故与取舍。

本版内容校准于 2026-10-27 的 main 分支(含上游全部历史提交);文中 `文件:行号` 对应该版本,行号会随 main 漂移,但函数名不会。

## 如何阅读这本书

- **[引言](intro)** 用一次真实的 agent 任务对比,说明"图"到底省下了什么;
- **总体架构** 一章给出全景流水线,建议所有人先读;
- **Tree-sitter 入门** 讲语法、错误恢复与 WASM,以及本仓对 tree-sitter 的非典型用法——好奇"为什么不用 `.scm` Query"的读者从这里进源码最顺;
- **实证** 一章做实验:造一个 3 文件的玩具仓库,用 CLI 真实索引它,打开 SQLite 逐表对账;
- **入门篇四章** 沿数据流动顺序展开:类型契约 → 提取 → 存储 → 查询,读完你应该能独立追踪一次完整的索引过程;
- **进阶篇六章** 各自独立,聚焦最难啃的部分:两阶段引用解析、动态分发与合成边、Rust 内核、MCP 进程拓扑、explore 工具的行为工程设计、性能工程;
- **定位与借鉴** 两章回答工程问题:这套系统适合什么场景、边界在哪(宏观 3 行);
- **附录** 是公共 API 到内部实现的导航表,供随手查阅。
